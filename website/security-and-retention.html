TRUST DETAILS

Security and retention by design

THUNDRA keeps architecture simple: local-first logic, short retention windows, and clear user controls.

Local-first alert engine

Nearby lightning checks and alert decisions are performed on-device using your configured radius and schedule.

Rolling retention window

Historical strike data is stored locally and automatically purged beyond a ~30 day window.

Security baseline

Network requests use HTTPS/TLS in transit.
No in-app advertising SDKs collecting behavioral profile data.
No account requirement for core feature access.

Data lifecycle

User settings and strike records remain on-device unless iOS backup behavior includes app data. THUNDRA does not operate a user cloud profile backend.
